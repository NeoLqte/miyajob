# 知識条件と採用対象で探す（2026-11-03）

確認済み・保留・未審査・すべての候補の一覧で、応募時の知識と採用対象を別々に選べます。確認済み一覧のURLにも skill と audience を保存し、既存の検索・勤務地・待遇・並び替えと組み合わせます。候補一覧は従来どおり状態・職種・勤務地・キーワード等とAND条件です。クリア操作で新しい条件も解除します。

## 応募時の知識

- 知識要件なし・育成の記載：応募資格に具体的な技術条件がない、または基礎からの育成が明記された求人。仕事が簡単、入社後の学習が不要という保証ではありません。
- 基礎知識・学習経験が必要：実務未経験でも、プログラミング学習・IT基礎・Office操作などの応募時の条件がある求人。
- 具体的な技術・経験条件あり：特定の開発・運用・設計・コード読解等を要求。企業実務に限定されるか不明な場合は、その点を根拠欄に残します。
- 必要知識は未確認：「未経験歓迎」や学歴不問だけで知識不要としません。未整理の求人もこの区分に残します。

## 採用対象

- 新卒・既卒対象の記載あり：新卒枠または既卒を明記した募集。新卒だけを対象とする枠も含むため、本人の既卒適用は根拠欄・既存保留理由を確認します。
- 中途・キャリア向け：当該枠がキャリア採用として案内されるもの。経験者限定とは限りません。
- 第二新卒枠（既卒適用に注意）：第二新卒歓迎と、就業歴なし既卒の受入を区別します。
- 採用区分は未確認：通年・随時・常時募集、ページの掲載期間の長さだけでは中途向けと断定しません。

フーリエの通年新卒募集は、保存根拠が就業経験のない既卒も対象としているため、新卒・既卒対象に分類。ROKIは基礎知識が必要なメンバー枠・第二新卒の区分で、職歴なし既卒適用は未確定のままです。シンク・エンジニアリングは実務経験と学生時代のプログラミング・Office基本操作を区別しています。
