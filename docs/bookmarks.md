# フォルダ付きブックマーク

確認済み・保留・未審査の各カード、確認済みの表・詳細から求人を保存できます。上部の「ブックマーク」で保存求人をまとめて開けます。既存の表示状態・検索・ソート・比較機能とは独立しています。

1. 求人の「保存」を押すと未分類へ追加。
2. 「ブックマーク」を開き、「新しいフォルダ名」に入力して作成。「近い会社」「未経験向け」「応募候補」など任意の名前を付けられます。
3. 保存した求人の「保存先」を開き、チェックでフォルダへ分類。同じ求人を複数フォルダに入れられます。
4. 保存フォルダの選択・会社名/職種/勤務地の検索で絞り込み。
5. 「フォルダの名前変更・削除」から名称を変更。フォルダを削除しても保存求人は残り、所属フォルダがなくなれば未分類になります。
6. 求人の「保存済み」を押すと、その求人のブックマークを解除します。

保存先は localStorage の miyajob.bookmarks.v1。ログイン・外部DB・有料サービスは不要で、保存情報をサーバーやGitHubへ送信しません。同じ端末・同じブラウザープロファイル・同じサイトで再読み込みしても保持されます。他端末・別ブラウザーとは同期せず、サイトデータ削除やプライベートブラウジング終了等で消えることがあります。エクスポート・バックアップ・入れ子フォルダは今回未実装です。

保存内容は求人ID・会社名・職種・勤務地・原典URL・保存時の確認状態/情報確認日・フォルダ所属のみ。本人のプロフィール・審査内部記録・応募履歴は保存しません。フォルダ名は1〜60文字、同名不可、最大100フォルダ・2,000求人です。

現在の公開データに同じIDの求人があれば、ブックマーク一覧の職種・勤務地・確認状態・確認日は現在の情報を表示します。見つからない場合は保存時の情報を残し、「現在の一覧にない保存求人」と表示。以前の確認済み状態から応募可能とは断定しません。状態変更・募集終了があってもブックマークを勝手に消しません。

保存失敗時に成功表示をせず、エラーを表示して既存データを保持。不正形式・不正な原典URL・参照先のないフォルダを拒否し、不正データを空の状態で上書きしません。同じブラウザーの別タブの変更をstorageイベントで取り込み、各操作時も最新の保存内容を読みます。

検証は複数フォルダへの登録、名称変更・削除後の求人保持、一覧から消えた求人の表示、容量不足と不正データの扱いを単体テスト。PC・スマホで確認済み/保留/未審査の保存、再読み込み後の保持、フォルダ絞り込み、名称変更、削除・解除をE2E確認します。求人データ・掲載判定・収集モードは変更していません。
