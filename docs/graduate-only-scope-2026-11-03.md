# 中途・キャリア募集を掲載対象外にする方針（2026-11-03）

中途・キャリア枠は、実務未経験可・既卒歓迎でも掲載対象外に変更。これはMiyaJobの掲載範囲の選択であり、すべての既卒者が一般に中途へ応募できないという意味ではありません。

確認済み・保留・未審査すべてから、明確に該当する28求人を除外しました。確認済みは8から5、保留は40から34、未審査は67から48。現在の閲覧総数は87件、累積除外は215件です。

確認済みから外したのは、アオイテックの中途未経験枠1件、テガラのキャリア枠2件。ほかにROKIメンバー枠、アクティシステム第二新卒の中途枠、アーティス2枠、NANA、ソフィックス、ウチゲン、モアソンのキャリア枠、スタッフ、システック、アルモニコスの中途枠、エーシステムの中途向けとして整理した枠、ヤマハモーターソリューションのキャリア5枠を非表示にしました。同じ企業の別の新卒枠をまとめて消していません。

追加で[スズキの公式キャリア採用サイト](https://www.suzuki-careers.com/)から[募集職種一覧](https://job.axol.jp/qd/c/suzuki/public/job/list)へのリンクを確認。保存していた該当8枠も除外しました。単に「転職サイトに載る」「通年募集」「URLにcareerという文字がある」というだけでは判定していません。紹介会社のcareerパス全体を除外する設定にはしていません。

採用区分が不明な求人は推測で中途とせず未確認に残します。新卒・既卒向けと記載があっても、職歴なし既卒への実際の適用が不明なら保留・未審査のままです。中途とは別の新卒・既卒向け募集は掲載できます。

## 実装

config/recruitment-policy.json に、明示確認した対象IDと、公式にキャリア枠として確認した情報源の範囲を保存。Pythonの審査・公開出力・収集の早期除外と、Webの公開データ読み込み・検索に同じ設定を使います。将来の収集でも明示的な中途採用区分や対象URL範囲を検出し、公開前に止めます。採用区分が不明な全求人を自動判定したという意味ではありません。

知識条件・採用対象の根拠データから掲載対象外の行を外し、中途・キャリアの表示フィルターも撤去。以前の分類は内部に保存しました。既存ブックマークに該当求人があれば通常の保存一覧・件数から隠し、データを削除せず保持します。

保存済みの調査記録・元の公開データは内部バックアップに保持。公開リポジトリの過去コミット・過去の調査報告は履歴であり、書き換えていません。現在の求人JSONと画面からは除外しています。

回帰確認は、未経験可でも中途区分なら対象外、通年新卒や不明区分を中途にしないこと、同社別新卒枠の保持、除外した保存求人を消さず隠すこと、既存の検索・ソート・地図・PC/スマホのフォルダ操作です。
